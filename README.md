## Reflection

Working with React and Tailwind felt pretty different compared to just using plain HTML, CSS, and JavaScript.

Setting everything up with Vite was actually not that bad. It’s definitely more steps than just opening an HTML file, but once it was set up, running the app with npm run dev was pretty easy  

The biggest thing I noticed was how React handles everything through state. Before, I was used to manually updating the DOM with things like getElementById, but here I just update the state and React takes care of updating the UI. It felt a bit weird at first, but once it clicked, it actually made things cleaner.

Tailwind was really nice to use. I liked how I didn’t have to write any separate CSS and could just style everything directly in className. It made it really fast to try different designs. The only downside is that the class names can get kind of long, messy and I have to constantly use online documentation. Tailwind will take a lot of time to get comfortable remembering styles and designs.

Overall, this stack feels really powerful but a bit more complex at the start. For something small like this, it might be a little overkill, but I can see how it would be really useful for bigger projects. Once everything is set up, it’s pretty easy and fast to work with.

I think I will use a lot React + Tailwind in the future to really practice my skills. Since I always wanted to focus on front-end dev
